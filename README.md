# TypeScript & OOP Assignment

This repository contains my practical solutions and technical blog posts for the TypeScript & OOP assignment.

## Coding Solutions (solutions.ts)

Write solutions for 8 core problems:

1. multiplyValue: Handles optional multipliers and default values (including proper 0 handling).

2. processInput: Type narrowing with union types (string, number, boolean).

3. formatCoordinate: Readonly tuple handling for exact coordinate formatting.

4. concatenateArrays: Generic rest parameters combining multiple arrays.

5. Course & getPopularCourses: Interface definition and array filtering without mutation.

6. pluckValues: Generic function with keyof constraints.

7. Employee & Manager: Object-oriented classes utilizing protected, private, and inheritance.

8. validateAgeAsync: Asynchronous promise-based validation handling resolves and rejections.
